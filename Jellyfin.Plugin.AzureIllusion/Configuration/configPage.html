Napisy z API AzureIllusion dla wybranych bibliotek Jellyfin.

Dokumentacja API
Klucz pozostaje wyłącznie na serwerze Jellyfin.
Codzienne zadanie podmienia plik tylko wtedy, gdy wersja na stronie się zmieniła, a lokalny plik nie był ręcznie edytowany. Usunięcie napisów ze strony nigdy nie usuwa pliku z Jellyfin.
Wybierz kilka bibliotek. Brak wyboru oznacza wszystkie. Miejsce zapisu wynika z ustawień danej biblioteki Jellyfin: napisy mogą trafić obok pliku wideo albo do wewnętrznego katalogu metadanych. Jeśli zapis obok wideo nie jest możliwy, Jellyfin bezpiecznie użyje katalogu metadanych.
Domyślnie plugin wyszukuje wydania wszystkich grup. Wybranie konkretnych grup włącza filtr.
Wybierz grupy — nie wybrano
Lista jest zwijana, przewijana i przeszukiwana, dlatego nie rozciągnie strony nawet przy dużej liczbie grup.
Możesz zaznaczyć kilka języków. Domyślnie wybrany jest polski.
0 oznacza brak limitu. To ograniczenie liczby grup zwracanych dla odcinka, a nie filtr dostępnych grup.
Gdy Jellyfin nie ma AniList ID, plugin zaakceptuje wynik tylko wtedy, gdy znajdzie dokładnie jeden identyczny tytuł z tym samym rokiem. Wyniki niejednoznaczne są pomijane.
